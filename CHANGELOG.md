# CHANGELOG

## [v.0.0.1](https://github.com/lilliputten/next-ai-helper-chat/releases/tag/v.0.0.1) - 2025.09.27

Created minimal working application, with the following features:

- Authorization (limited by allowed users).
- Administrative page for edition of the allowed users list.
- AI API support (for Cloudflare and GigaChat).
- Test AI query pages (for text and image queries).
- The first registered user authomatically treated as an admin.
